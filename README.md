# FitLog — Workout Library

A modern and responsive workout library website built with Next.js. Explore exercises, view workout details, and organize your daily fitness plan with a clean and user-friendly interface.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI

## Key Features

1. **Workout Library:** Browse workouts with images, equipment, muscle groups, duration, calories, and ratings.
2. **Workout Sorting:** Sort workouts by duration, calories, or rating.
3. **Workout Details:** View detailed information about each exercise using API data.
4. **My Plan:** Add exercises to your daily plan and save workouts for later.
5. **Responsive Design:** A mobile-friendly layout with responsive navigation.
6. **Loading Animation:** Display a loading animation while workout data is being fetched.
7. **404 Page:** Show a custom error page when a user visits an invalid route.
8. **Toast Notifications:** Display notifications when users add or save workouts.
